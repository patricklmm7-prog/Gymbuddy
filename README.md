# GymBuddyTO - Supabase 版

## 為什麼用 Supabase？
- 開源、PostgreSQL
- Auth（Google + Email）好用
- Realtime 聊天
- 免費額度足夠做Demo

## 設定步驟

1. 去 [supabase.com](https://supabase.com) 創建新項目

2. **Authentication** → Providers：
   - 開啟 Email
   - 開啟 Google（要填 Google Client ID/Secret）

3. **SQL Editor** 執行以下建立 tables：

```sql
-- Profiles
create table profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  name text,
  email text,
  photo_url text,
  area text,
  gym text,
  time text,
  goal text,
  bio text,
  created_at timestamptz default now()
);

-- Messages
create table messages (
  id bigint generated by default as identity primary key,
  room_id text not null,
  user_id uuid references auth.users(id),
  text text not null,
  created_at timestamptz default now()
);

-- RLS
alter table profiles enable row level security;
alter table messages enable row level security;

create policy "Public profiles are viewable by everyone" on profiles for select using (true);
create policy "Users can insert their own profile" on profiles for insert with check (auth.uid() = id);
create policy "Users can update own profile" on profiles for update using (auth.uid() = id);

create policy "Messages are viewable by authenticated" on messages for select using (auth.role() = 'authenticated');
create policy "Authenticated users can insert messages" on messages for insert with check (auth.role() = 'authenticated');
```

4. 喺 Project Settings → API 複製：
   - Project URL
   - anon public key

5. 打開 `index.html`，替換 `SUPABASE_URL` 同 `SUPABASE_ANON_KEY`

## 功能
- Google / Email 登入
- 用戶 Profile
- 即時聊天（Realtime）
- Gym 地圖

設定好就可以用！
